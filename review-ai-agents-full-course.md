# Разбор: justxor/Aiagentsfullcourse

Дата разбора: 2026-08-16. Метод: клонирование, полная проверка структуры, запуск кода, чтение модулей.

## Паспорт

- Создан **15.08.2026 (за день до разбора)**, 32 коммита за сутки, 1 автор, 20 звёзд, ни лицензии, ни обсуждений.
- Контент-маркетинг для сети Telegram-каналов («Machine Learning», «Data Science», «Machine Interview») — реклама вшита в шапку README.
- 31 файл, ~9700 строк маркдауна, **один файл кода**: `01-agent-basics/code/agent.py` (540 строк).
- Курс на русском: 14 модулей (основы агентов → tool calling → планирование → память → RAG → MCP → мультиагентность → песочницы → эвалы → наблюдаемость → безопасность → стоимость → эксплуатация → отказы) + разделы labs/projects/benchmarks/templates/checklists/anti-patterns.

## Сильное

- Текст модулей добротный, инженерный, без воды. Образец — модуль 14 «Отказы агентов»: таксономия 30 отказов по 6 слоям с признаком в трейсе и лечением у каждого; дерево диагностики.
- Верный сквозной тезис: качество агента упирается не в модель, а в обвязку (описания инструментов, контекст, проверки, бюджеты).
- Единственный код-файл хороший: запускается без ключей (детерминированная заглушка), иммутабельная задача, 4 бюджета, разделение history/window, коды причин выхода, трейс в JSONL. Проверено — работает.
- Справочный слой существует: 4 чек-листа (перед первым запуском, перед продом, ревью, инцидент), каталог антипаттернов.

## Слабое: практика — фасад

- Из **20 обещанных лабораторных существует одна** (lab01), и та — только README без кода (даже упомянутый в ней test_lab01.py отсутствует). Ссылки на lab02–lab20 битые.
- **Makefile с 27 целями — бутафория**: `make doctor/eval/check/...` ссылаются на tools/doctor.py, labs/*/tests, наборы эвалов — ничего не существует. Работает только `make install`.
- 6 «проектов» — описания и рубрики, ноль кода. Бенчмарки — методика без наборов задач. templates/ обещает agent-skeleton/docker/ci — есть только .env.example.
- Критерии приёмки модулей («make check m14») непроверяемы; числа («golden set 60+ задач», «recall@30 > 0,90») без данных.

## Время

Заявлено: треки 25 / 70 / 160 ч. Реально репозиторий поддерживает единственный режим — **чтение, 15–25 ч**. Вся практика — работа, которую надо спроектировать самому по текстовому ТЗ.
