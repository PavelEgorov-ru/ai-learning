# Журнал курса

Память курса между сессиями. Репетитор дописывает запись в конце каждой сессии по шаблону ниже. Новые записи — сверху.

Шаблон записи:

```
## ГГГГ-ММ-ДД — урок N.K «Название»
- Сделано: …
- Квиз: X/Y; западает: …
- Артефакт: готов / не готов (что осталось)
- Решение по маршруту: — (заполняется при ревизии курса или срабатывании стоп-правила: что меняем и почему)
- Версия курса: N (из шапки 00-overview.md)
- Заметки: … (сюда же: кандидаты на мини-уроки, достигнутые вехи, созданные репозитории с путями)
```
