# Разбор: rohitg00/ai-engineering-from-scratch

Дата разбора: 2026-08-16. Метод: клонирование, статистика по файлам, запуск кода, два субагента прочитали ~12 уроков целиком.

## Паспорт

- 47 тыс. звёзд, 8,2 тыс. форков; создан 18.03.2026, к июню «завершены» все 503 урока; 93% коммитов — один автор (rohitg00) → масштабная LLM-генерация с частичной ручной доводкой.
- 20 фаз, 503 урока, 3200 файлов, ~46 тыс. строк Python (585 файлов), 129 TS. «4 языка» — преувеличение: Julia 20 файлов, Rust 10.
- Формат урока единый: Problem → Concept → Build It (с нуля) → Use It (то же на PyTorch/sklearn) → Ship It (артефакт: промпт/скилл/MCP) → упражнения → термины → литература.
- Агент-репетитор: `npx skills add rohitg00/ai-engineering-from-scratch`, затем `/start-learning` (входной тест → план в LEARNING.md) и `/learn` (урок за сессию: повторение → разбор → квиз → журнал). Педагогика грамотная (интервальное повторение, очередь пересдач при <70%).
- Дополнительно: сайт aiengineeringfromscratch.com, 6-томная книга (EPUB/PDF в releases), сертификационная академия Claude (32 урока, 4 трека, полные пробные экзамены), переводы на 12 языков (машинные).

## Системные дефекты

- Метаданные не сверялись: README «~320 ч» vs ROADMAP внизу «~1050 ч» (сумма фаз 0–18 ≈ 474 ч + капстоуны ~620).
- Квизы только у 338/503 уроков; у фаз 6, 8, 9, 12, 13, 15 — ноль → репетитор `/learn` там молча деградирует (нечем делать warm-up и Review queue).
- Выводы программ в доках местами выдуманы (не совпадают с фактическим прогоном).
- В requirements.txt нет `regex`, нужного ключевому уроку фазы 10.
- На Windows нужен `PYTHONIOENCODING=utf-8` (юникод в выводе).

## Время реально

- Ядро (фазы 0–18): ~350–450 ч (не 320).
- +2–3 капстоуна как задумано: +150–300 ч (ТЗ описывают по 80–150 ч работы каждое).
- Выборочный трек «уже знаю ML, нужны агенты/LLM» (фазы 7, 10–16): ~120–180 ч.

## Вердикт

Использовать выборочно: фазы 1–3 для основ, 13–14 для MCP/агентов, сертификационный модуль для экзаменов Claude. Фазы 7 и 10 — только как конспект для знающего; для «LLM с нуля» честнее Karpathy (nanoGPT/llm.c). Закономерность: текст вычитан лучше кода, код лучше связки «текст↔код», метаданные не сверялись вовсе.
